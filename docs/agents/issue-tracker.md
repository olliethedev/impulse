# Issue tracker

This repository uses GitHub Issues at `olliethedev/impulse`. Use `gh issue view NUMBER --repo olliethedev/impulse` to read an issue, and structured tool arguments or `--body-file` for issue bodies. The implementation specification is currently local at `docs/spec.md`.

External pull requests are not automatically a triage request surface. Repository visibility is a maintainer setting; implementing an OSS license does not change it. Do not publish messages or change repository settings without task authorization.
