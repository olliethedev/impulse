# Agent skill

The installable skill is [skills/impulse/SKILL.md](skills/impulse/SKILL.md). It follows the standard directory layout used by Codex and Claude Code.

Install the bundled copy with `impulse skill install --harness codex --scope user`, select `claude-code`, or use `--dir PATH` for another environment. Existing user modifications are preserved by rejecting an overwrite. The skill provides usage instructions; it does not grant extra execution permissions.
